# plant-care

観葉植物のお世話をサポートするWebアプリ。

水のやりすぎを防ぎ、植物の種類に応じた適切なケアを支援することを目的としています。

## 主な機能

- 植物カードの登録・一覧表示(種類・ニックネーム・置き場所・迎えた日)
- 季節を考慮した水やり判定(まだ早い / そろそろOK / 遅れ気味)
- 水やり履歴の記録とカレンダー表示
- 困ったときのトラブル相談(症状別の原因と対処法)
- データのエクスポート / インポート(JSON形式)

## 公開URL

https://hariyumi0416.github.io/plant-care/

スマートフォンの Safari / Chrome で開けます。ホーム画面に追加するとアプリのように使えます。

## データの扱い

- すべてのデータはお使いのブラウザ内(LocalStorage)に保存されます
- 外部サーバーへのデータ送信は一切行いません
- 機種変更や Safari のデータ消失に備え、定期的にエクスポート機能でバックアップを取ることを推奨します

## 技術構成

- HTML / CSS / JavaScript(バニラJS、フレームワーク不使用)
- ブラウザの LocalStorage に保存
- ビルドツール / 外部ライブラリ不使用

## ローカルで動かしたい場合

`file:///` で直接開くと JSON ファイルの読み込みがブラウザのセキュリティ制限でブロックされるため、簡易的なローカルサーバーを起動します。

cd <このフォルダのパス>
python3 -m http.server 8000

ブラウザで `http://localhost:8000` にアクセスしてください。

サーバーを停止するときはターミナルで `Ctrl + C` を押します。
